The “Rating ±” column is demo rating uncertainty, not a parameter confidence interval. Method/task availability is not verified.

Proposed battle protocol

For each task, draw a data-generating process (DGP) with a known true estimand. Repeat sampling at a fixed DGP; run methods on paired datasets; measure coverage, width, RMSE, and time. A proposed interval score is (hi−lo) + 2/α · max(lo−θ,0) + 2/α · max(θ−hi,0). This is a design sketch, not an executed benchmark.

Potential method families

Compare native inference PFNs, prediction PFNs with explicit inference wrappers, and classical estimators on the SAME defined estimand. Names shown above are illustrative candidates only; they do not imply a released method supports every listed task. Separate confidence intervals from predictive intervals.

Proposed submission interface

A future harness could accept estimate_and_interval(data, task_spec) → (estimate, lo, hi), record training/calibration budgets and evaluate fixed-DGP repeated sampling plus held-out families. There is no live submission endpoint or public evaluation service yet.
