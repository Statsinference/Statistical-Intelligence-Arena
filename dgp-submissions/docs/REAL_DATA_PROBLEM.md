# Contribute a real-data problem

Propose one answerable causal question for an existing dataset with a documented source or an authorized access route.

## What to include

- **Question and estimand.** State the intervention or exposure, comparison, outcome, time horizon and target population. Define the causal estimand and its units.
- **Data and access.** Cite the original study and link the dataset or its access instructions. Describe the observational unit, variable roles and relevant measurement times. Explain the applicable permissions and shareable materials.
- **Study design and assumptions.** Describe assignment, confounding, missingness or other design features that matter. Include a DAG or an arrow list when useful, and state the assumptions and limitations of the interpretation.
- **Evaluation.** Give a randomized, design-based or published reference estimate with its uncertainty when available, and say which population and estimand it describes. Without a credible reference, propose concrete comparisons of estimates and intervals, sensitivity checks or tests of stability. Identify a baseline, and describe the expected method outputs.

## Open a pull request

Use the [real-data template](https://github.com/Statsinference/statsinference.github.io/blob/5e174c855669b16bef0a459e1b8587fdec892e56/data-submissions/real-data/TEMPLATE.md) and the [filled supported work and earnings example](https://github.com/Statsinference/statsinference.github.io/blob/5e174c855669b16bef0a459e1b8587fdec892e56/data-submissions/real-data/EXAMPLE.md). Put one completed Markdown file under `data-submissions/real-data/submissions/` in your fork and open a PR against [the website repository's main branch](https://github.com/Statsinference/statsinference.github.io/tree/main). A maintainer assigns a reviewer after the format check.

Link to authorized sources or the official access process. Arrange any review of restricted records with a maintainer before transferring them.
