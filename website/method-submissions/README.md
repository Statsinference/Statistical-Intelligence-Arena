# Submit a method to StatArena

Prepare these three items for a statistical method or model you want evaluated.

1. **Method link.** Provide a public link to a runnable implementation, such as a GitHub repository or a Hugging Face model page. Include access to any weights needed to run it.
2. **Research domain.** Select the domain you want the method evaluated on.
3. **Completed checklist.** Copy the [method checklist template](method-checklist.md), answer each section, and paste the completed Markdown into the **Completed checklist** field.

Submissions are public GitHub issues. The StatArena team reviews each submission and evaluates eligible methods for the official leaderboard.

**[Submit a method](https://github.com/Statsinference/statsinference.github.io/issues/new?template=method-submission.yml)**
