# Simulated DGP

Propose a reproducible data-generating process with an estimand and a known reference value. Explain which study setting motivates it, or which statistical behavior it isolates, and justify the key design choices.

Copy the [simulation template](TEMPLATE.md) to `data-submissions/simulated-dgp/submissions/<slug>.md`. See the [childhood trauma, DNA methylation and cortisol example](EXAMPLE.md) for a filled contribution.

For a public teaching design, link to reproducible materials when redistribution is authorized. For a candidate evaluation design, give a shareable public summary and use the maintainers' private channel for the full generator, exact configurations, seeds and truths.
