# Real-data problem

Propose an answerable question for a dataset with a documented source or authorized access route. Define the target population and estimand, and explain what the study design supports.

Copy the [real-data template](TEMPLATE.md) to `data-submissions/real-data/submissions/<slug>.md`. See the [supported work and earnings example](EXAMPLE.md) for a filled contribution.

A credible reference estimate is useful when available. Otherwise, propose an evaluation of estimate stability, uncertainty or sensitivity to assumptions. Share a dataset link or the official access process rather than attaching participant records to the PR.
