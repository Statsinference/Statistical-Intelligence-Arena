A scientific task before a leaderboard.

Six candidate families define the initial scope. Begin with one complete mediation pilot; the family list is a development plan.

One canonical setting

Fix the estimand, identification conditions, sampling unit, and known or independently checked numerical truth.

A supported reference comparison

Reproduce the strongest classical/reference baseline supported by that setting and the available evidence. Label PFN outputs as native or adapted.

Two distinct generalization tests

New seeds within training mechanisms measure in-distribution behavior. Held-out mechanisms test transfer. A classic published DGP is not automatically unseen.

Layer B is required: a fixed causal target and design go in; an estimate, supported interval, diagnostics, and status come out. Layer A is optional: evaluate the complete scientific analysis separately, including its choices and assumptions.

Which causal question?

Each family needs its own target, design, and interval validity conditions.

Average treatment effect

What is the average treatment contrast in the declared population?

ATE = E[Y(1) − Y(0)]

Specify treatment, outcome, covariates, population, and assignment. Randomization or observational identification, consistency, exchangeability, and positivity must match the setting.

What can run now, and what still needs implementation?

The starter includes standard-library structural and output-contract checks. After unpacking it, run these from the package root:

python validate_submission.py --mode scaffold
python evaluation/check_contract.py

These check the scaffold and positive/negative output-contract fixtures. They do not train a PFN, parse and execute the entire scientific protocol, verify identification, or certify coverage. Training and evaluation command interfaces remain planned; the student must implement and document the actual runnable commands.

Fill the existing templates, replace illustrative unsupported outputs with actual run records when available, and retain explicit unsupported status where a method cannot supply the requested interval. A scaffold check alone is not a completed contribution.

Planned mediation pilot · the scientific core

Begin with a simple identified mediation DGP, independent observations, and a checked parametric reference. Choose NIE or NDE explicitly; store the other as a separate target if included.

NIE = E[Y(1,M(1)) − Y(1,M(0))]
NDE = E[Y(1,M(0)) − Y(0,M(0))]

Declare treatment, mediator, outcome, covariates, timing, support, and required confounding/cross-world assumptions. Derive or independently compute truth before expanding the mechanism mixture. A target formula alone does not establish identification.

The worked demo is planned, not supplied as a trained checkpoint or verified reference implementation. The guides explain the development sequence and expected evidence.

Fair comparisons, splits, and reference selection

Keep canonical evaluation separate from stress tests: weak overlap, model misspecification, weak instruments, weak proxies, or a changed design. Select the strongest reference supported by the particular target and evidence; an unverified “best method” is not a baseline specification.

Match the total observed-label budget across classical and PFN methods, including fitting, tuning, and calibration. Disclose simulation supervision and pretraining separately. Native outputs and adapted wrappers must be labeled; count wrapper resampling, correction, or refitting in online cost.

Record DGP citations and any known pretraining exposure. Classic DGPs alone do not resolve contamination. Declare mixture weights and parameter ranges within each task-conditional Π_k; keep held-out mechanism definitions and evaluation-only truth under independent custody. A future model spanning families must condition on the target, roles, and query or use distinct output heads; do not pool six incompatible scalar estimands as one output. Real-data papers and public expert crowdsourcing are not required for the initial pilots.

Evaluate causal confidence intervals

Compare within a fixed estimand, DGP, sampling design, interval scope, and regime. No global ranking is defined.

Layer B · numerical evidence

Estimation
Bias and RMSE against independently checked causal truth. For CATE, start with a scalar effect at a prespecified query.
Coverage
Repeated-sampling coverage and a Monte Carlo band. The proposed default is 95%; preregister its level separately from the method’s nominal interval level.
Length
Compare interval length only after the preregistered validity gate. Retain unbounded intervals and disclose any confidence-set extension.
Failures
Report interval availability, unsupported outputs, abstentions, crashes, and timeouts across all attempts.
Transfer
Separate canonical, stress, new-seed, and held-out-mechanism results; retain per-DGP evidence.
Cost
Report loading, inference, wrapper calibration/refitting, memory, and hardware; offline training and simulation costs separately.

Validity before efficiency

Preregister a coverage gate

At each fixed DGP, specify nominal coverage, tolerance, repetitions, Monte Carlo bound, coverage denominator, and an interval-availability rule. Classify validity as pass, fail, or inconclusive.

Repeat the correct independent unit

Generate independent datasets or design replications. Preserve clustering and panel dependence within each replication. Multiple rows or correlated queries are not independent Monte Carlo trials.

State exactly what is covered

A scalar causal-parameter CI has a fixed target. CATE coverage at one fixed query does not imply simultaneous coverage or validity at every covariate value. Posterior credible intervals retain a different interpretation.

Keep Layer A separate

Optional complete-analysis evaluation includes scientific choices and assumptions. Its coverage requires repeating the full pipeline, including selection and preprocessing.

Denominators, interval semantics, and private evaluation

Report both valid-output coverage and the probability of returning a valid covering interval across all attempted runs, together with availability and failure rates. Define how empty, unbounded, malformed, and unsupported outputs enter each metric before testing. Never silently remove failures from the denominator.

A 95% Monte Carlo band describes uncertainty in the measured coverage, not uncertainty about the causal estimand. Compare length only after the declared validity gate; retain per-DGP results so pooled averages cannot conceal a failing mechanism.

Weak-IV confidence sets may be unbounded or disconnected. Use a target-compatible confidence-set contract and reference method; do not clip sets to make length finite or silently replace a disconnected set by a connected interval. An unsupported set representation requires an explicit extension before comparison.

Freeze methods before private testing. Match observed-label budgets and report offline and online costs separately. Keep evaluation-only truth and latent simulator information out of learner inputs. New random seeds do not establish that a mechanism was absent from pretraining.
